# Security policy

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub:
**[Report a vulnerability](https://github.com/Anas2103/Relay/security/advisories/new)**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply within 7 days. Please give us a reasonable time to fix it before telling anyone else.

## Scope

In scope: the live app at https://relay-chat.bunbunchat.workers.dev and this repository.
Out of scope: denial-of-service or load testing, social engineering, attacks needing a compromised device, and issues in Cloudflare itself.

Test only with accounts you created. Don't read, change or delete other people's data.

## Supported versions

Only the latest deployed version is supported.

What's already in place is described in [docs/SECURITY_MEASURES.md](docs/SECURITY_MEASURES.md).
